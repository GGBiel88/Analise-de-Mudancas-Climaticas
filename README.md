# Análise de Mudanças Climáticas

Introdução

O projeto Análise de Mudanças Climáticas tem como objetivo desenvolver um dashboard interativo para analisar as mudanças climáticas em diferentes cidades brasileiras, utilizando dados meteorológicos históricos.

Por meio de técnicas básicas de Ciência de Dados, o sistema permitirá visualizar e comparar informações sobre temperatura e precipitação ao longo dos anos, buscando identificar tendências, variações e possíveis alterações nos padrões climáticos.

Contextualização

As mudanças climáticas representam um dos principais desafios ambientais da atualidade, podendo afetar diretamente a qualidade de vida da população, a agricultura, os recursos hídricos e a economia.

Diante desse cenário, a análise de dados históricos é uma ferramenta importante para compreender o comportamento do clima e identificar tendências ao longo do tempo.

O projeto busca facilitar o acesso a essas informações por meio de gráficos e indicadores interativos, permitindo que qualquer pessoa explore os dados e compreenda melhor as transformações climáticas observadas em diferentes regiões do Brasil.

Fontes dos Dados

A principal fonte de dados será a Open-Meteo Historical Weather API, que disponibiliza informações meteorológicas históricas, incluindo temperatura, precipitação e outras variáveis climáticas.

A API oferece acesso gratuito para uso não comercial, sem necessidade de autenticação, sendo adequada para o desenvolvimento do projeto acadêmico.

Os dados coletados serão armazenados localmente em arquivos CSV ou JSON e posteriormente tratados para utilização no dashboard.

Tecnologias Utilizadas

O projeto será desenvolvido utilizando as seguintes tecnologias:

- Python: linguagem principal para desenvolvimento do projeto.
- Requests: biblioteca para realizar requisições à API e coletar os dados.
- Pandas: biblioteca utilizada para limpeza, organização e transformação dos dados.
- NumPy: biblioteca para cálculos numéricos e estatísticos.
- Plotly: ferramenta para criação de gráficos interativos.
- Streamlit: framework para desenvolvimento da interface do dashboard.
- CSV/JSON: formatos utilizados para armazenamento local dos dados.
- GitHub: plataforma para armazenamento, documentação e compartilhamento do código-fonte.
